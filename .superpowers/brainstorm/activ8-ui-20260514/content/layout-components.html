Core components

  • App shell: persistent left nav, top command header, account/status cluster.
  • Metric tiles: fewer, larger, readable KPIs instead of tiny bordered stats everywhere.
  • Primary workspace: one active task per screen, not stacked panels competing for attention.
  • Inspector rail: right column for featured synthesis, verified links, warnings, and context.
  • Status chips: small, calm labels for queue/risk/phase/uplink state.
  • Action buttons: one strong primary action, secondary actions as quiet outline buttons.

Surface-by-surface

  • Login: cinematic access screen, centered form, cleaner brand mark, no social-button clutter unless wired.
  • Hub: overview dashboard with queue depth, Sophia state, phase, featured answer, and event stream.
  • Ask Sophia: large prompt composer with category/risk controls and priority preview.
  • Sophia Live: streaming synthesis feed with one featured output and compact archive.
  • Admin: queue table, filters, synthesis preview modal, clear approve/feature/reject actions.
  • Mobile: top status header, bottom tab bar, single-column workspace, no horizontal nav wrap.
